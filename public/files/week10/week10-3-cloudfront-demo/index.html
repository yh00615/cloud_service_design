Version: 1.0

빠르고 간편한 레스토랑 예약

QuickTable은 전 세계 사용자가 레스토랑을 검색하고 예약할 수 있는 글로벌 서비스입니다. Amazon CloudFront CDN을 통해 서울, 도쿄, 뉴욕, 런던 등 어디서나 빠른 응답 속도를 제공합니다.

서비스 특징

🌏 글로벌 배포

Amazon CloudFront의 전 세계 엣지 로케이션을 통해 어디서나 빠르게 접근할 수 있습니다.

🔒 안전한 접근

OAC(Origin Access Control)로 S3 오리진을 보호하고, HTTPS를 통해 안전하게 서비스합니다.

⚡ 빠른 응답

엣지 로케이션 캐싱으로 사용자와 가장 가까운 위치에서 콘텐츠를 제공합니다.

🔄 실시간 업데이트

캐시 무효화를 통해 레스토랑 정보와 메뉴를 즉시 갱신할 수 있습니다.

캐싱 테스트

이 페이지는 Amazon CloudFront를 통해 전달되고 있습니다. 아래 버튼으로 캐싱 동작을 확인하세요.

캐시 상태 확인 방법

브라우저 개발자 도구(F12)를 열고 Network 탭에서 다음 응답 헤더를 확인하세요:

  • x-cache: Hit from cloudfront (캐시 히트) 또는 Miss from cloudfront (캐시 미스)
  • x-amz-cf-pop: 요청을 처리한 엣지 로케이션 (예: ICN54-C1은 서울)
  • age: 캐시된 시간 (초 단위)

캐시 무효화 (Invalidation)

S3에 새 파일을 업로드해도 TTL이 만료되기 전까지는 이전 버전이 제공됩니다. CloudFront 콘솔에서 캐시를 무효화하여 즉시 새 콘텐츠를 배포할 수 있습니다.

# AWS CLI로 캐시 무효화
aws cloudfront create-invalidation \
  --distribution-id YOUR_DISTRIBUTION_ID \
  --paths "/*"
