# Week 10-3: Amazon CloudFront CDN 배포 및 캐싱 전략

## 포함 파일

- `index.html` - QuickTable 메인 페이지 (레스토랑 예약 서비스 소개, 캐싱 테스트 UI)
- `about.html` - QuickTable 소개 페이지 (글로벌 아키텍처, 캐싱 전략 가이드, 문제 해결)
- `style.css` - QuickTable 스타일시트 (반응형 디자인, 캐싱 테스트용)
